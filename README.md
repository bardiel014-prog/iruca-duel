# 剣姫の一手

公開先: https://iruca.tech/duel/

2026-11-24時点の公開版から独立させたソースリポジトリです。リポジトリへのpushだけでは本番は更新されません。

## ローカルで画面を開く

```sh
python -m http.server 8000 --directory public
```

`http://localhost:8000/` を開いてください。このコマンドは画面の確認用で、通信対戦・集計APIは別途必要です。

## 通信対戦・解析

`backend/server.mjs` と `backend/rules.mjs` は現在の通信対戦処理です。Node.js 24以上が必要です。`HOST`・`PORT`・`KENKI_DB` で待受と保存先を指定し、`/duel/friend-api` を転送してください。フロントは `public/` から別途静的配信します（このサーバー内蔵の静的配信は旧版用です）。

`analytics/server.py` は任意の匿名集計サービスです。集計結果・DBは含めていません。レポート用の経路を認証なしで公開しないでください。

## 公開物の範囲

ゲームコードと必要な画像・音声を収録しています。本番の部屋データ、アクセスログ、集計結果、認証情報、非公開運用文書は含みません。

ソース・画像・音声の再利用許諾を新たに付与するものではありません。ライセンスは別途定めるまで未設定です。
