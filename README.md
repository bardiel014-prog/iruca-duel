# 剣姫の一手

公開先: https://iruca.tech/duel/

2026-11-24時点の公開版から独立させたソースリポジトリです。リポジトリへのpushだけでは本番は更新されません。

## ローカルで画面を開く

```sh
python -m http.server 8000 --directory public
```

`http://localhost:8000/` を開いてください。このコマンドは画面の確認用で、通信対戦・集計APIは別途必要です。

## 通信対戦・解析

`backend/server.mjs` と `backend/rules.mjs` は現在の通信対戦処理です。Node.js 24以上が必要です。`HOST`・`PORT`・`KENKI_DB` で待受と保存先を指定し、`/duel/friend-api` を転送してください。フロントは `public/` から別途静的配信します（このサーバー内蔵の静的配信は旧版用です）。

`analytics/server.py` は任意の匿名集計サービスです。集計結果・DBは含めていません。レポート用の経路を認証なしで公開しないでください。

## 開発中に重視したポイント

ChatGPTとのルール検討、キャラクター紹介・イラストの調整、試遊フィードバックで扱った内容をまとめています。調整の経緯は過去の検討であり、現行の数値はゲーム画面とルール実装を参照してください。

- **短い対戦で読み合いを成立させる。** ライフ8を軸に、強襲・牽制・フェイントと受け技の組み合わせを検討しました。技を決める前に、消費する札の種類・枚数と、相手の受け方による結果を確認できる表示を重視しました。
- **回避によって牽制の連打にも判断を要求する。** イリスの牽制と制圧をつなぐ手順を検討したことから、牽制・フェイントを無傷でかわし、強襲には大きく削られる常設の回避を追加しました。各キャラの固有技も含めて勝ち筋と紹介文を見直しました。
- **ノアは初手から大技を意識させる。** 捨て身の強襲でガードと回避に圧力をかけ、相手が選びたくなるカウンターを牽制・フェイントで消費させる方針を整理しました。背水は通常強襲と捨て身の強襲の両方に適用する調整を行いました。
- **静流はカウンター札を使う判断に個性を持たせる。** 心眼で技を確認してから受けを選び、貴重なカウンターの無駄打ちを減らす設計です。「読むな。見ろ。」という方針を紹介文にも反映しました。
- **選択結果の表示をライフ変動にそろえる。** 選択肢を1行カードにし、選択後は相手の行動ごとに結果を表示する形式を検討しました。相手へのダメージは赤字、自分へのダメージは青字とし、パッシブによる追加効果も確認できる形にしました。チュートリアルでは自傷の帰属と表示上の自分・相手の対応も確認点になりました。
- **専用技の絵でキャラごとの差を出す。** 攻撃を受ける相手の視点と覚醒表情を基準に、距離感、動き、武器の見え方を調整しました。ヴィオレッタは薔薇、ノアは茨を主モチーフとし、衣装・髪型の設定、手指、腕と剣の長さ、脚のつながりを見直しました。
